# Pokémon UNITE カウンターピックメーカー

ポケモンユナイトにおける、自分や構成に合わせた「ターゲット」「有利」「不利」などのポケモン相性を整理し、保存・共有できるWebアプリケーションです。  
ドラッグ＆ドロップによる直感的な操作と、閲覧に特化した「ビューモード」を備え、自分だけのカウンターピックリストを簡単に作成できます。

## 🚀 主な機能

- **直感的なドラッグ＆ドロップ操作**：ポケモン一覧（プール）から各項目へ、項目間から別の項目へ自由に移動。
- **閲覧専用の「ビューモード」**：Pinterest風の美しいグリッドレイアウトで、構築したセットを一覧表示。
- **URLを使った共有機能**：作成したリストを圧縮URL化し、SNSや友人にシェアすることが可能（URLパラメータでデータを復元）。
- **カスタマイズ性の高さ**：セット名や各カテゴリ（項目）名を自由に編集可能。項目の順番の入れ替えにも対応。
- **オートセーブ**：操作するたびにブラウザの `localStorage` へ自動保存。次回アクセス時にそのまま再開できます。
- **レスポンシブデザイン**：PC・タブレット向けのリッチなレイアウトと、スマートフォン向けに最適化されたコンパクトUIを両立。

## ✨ 工夫した点（技術・設計のポイント）

ポートフォリオとして閲覧いただく方向けに、UX やデータ設計面で特に注力したポイントをまとめています。

### 1. 表示画面の見やすさ（ビューモードの視認性設計）
- **Pinterest 風の自動マルチカラムレイアウト**：ビューモードでは CSS の `column-width` と `break-inside: avoid` を組み合わせ、画面幅に応じて列数が自動で増減しつつカードが途中で途切れない一覧表示を実現しています。
- **情報の優先度に応じた強弱と余白の最適化**：各セットの先頭項目（ターゲット）のポケモンアイコンを大きく表示して一目で判別できるようにし、デフォルト名（「セット1」や「ターゲット」など）は閲覧時に自動で非表示にして視認性を高めています。
- **ロール別のカラーリング**：アタック・ディフェンス・スピード・バランス・サポートの5ロールごとにアイコンの背景色を分け、一覧から直感的に役割を把握できるようにしました。

### 2. カスタマイズに幅をもたせる柔軟なデータ設計
- **動的な項目（カテゴリ）構成**：固定の「有利／不利」2枠に縛らず、`items` 配列として項目を自由に増減・リネームできる構造にしました。「ターゲット / 有利 / 微有利 / 不利 / 要注意」など、プレイヤーごとの思考や構成に合わせたリストを作成できます。
- **編集モードとビューモードの分離**：編集時のみポケモン選択プールや並び替え・削除コントロールを表示し、閲覧時はリストの確認に集中できるクリーンな画面へと切り替えます。

### 3. 共有リンク作成のこだわり（サーバーレスでの URL 圧縮・互換性）
- **圧縮 API による URL 長の削減**：バックエンドや DB を持たない静的サイト（GitHub Pages）構成のまま共有機能を実現するため、ブラウザ標準の `CompressionStream`（`deflate-raw`）でデータを圧縮し、URL-safe Base64 へ変換してクエリパラメータに格納しています。
- **シリアライズ時の徹底した軽量化**：
  - ポケモン情報全体ではなく **数値 ID のみ** を保存し、未選択プールは復元時にマスターデータから再計算。
  - JSON キーの短縮（`name` → `n`、`items` → `i`、`pokemons` → `p`）、デフォルト項目名の省略、空セットの除外を行い、圧縮前データそのものを最小化しています。
- **後方互換性と安全なデータ復元**：データ形式のアップデート後も過去の共有 URL が開けるよう、非圧縮 JSON や旧キー名・英語名（`en_name`）からのフォールバック復元に対応しています。また、共有 URL を開いた際はローカルの保存データを即座に上書きせず、「元のデータに戻す」か「上書き保存する」かをユーザーが選べる設計にしました。

### 4. スマートフォンでも使いやすいレスポンシブ UX
- **デバイスに応じた操作方式の最適化（D&D 誤爆防止）**：PC では `@dnd-kit` によるドラッグ＆ドロップを採用しつつ、モバイル幅（820px 以下）では画面スクロールとの競合を防ぐため、センサーの閾値・遅延設定によりドラッグ操作を実質無効化しています。代わりに **「ポケモンをタップして選択 → 移動先の項目をタップして配置」** という、片手でも誤操作しにくいタップ操作へ自動で切り替わります。
- **`rem` と `clamp()` による流動的スケーリング**：`src/constants/cssSize.ts` に px → rem 変換（`Size`）および画面幅に応じた線形補間（`VariableSize`）のヘルパーを用意し、Linaria のスタイル定義全体で一貫したスケーリングを実現しています。
- **狭小画面向けのレイアウト調整**：モバイル幅ではビューモードを強制1列表示に切り替え、ヘッダー操作も折りたたみ可能な構成にすることで、限られた画面領域でも快適に操作できます。

## 🛠 技術スタック

- **Framework**: React 19
- **Build Tool**: Vite (TypeScript)
- **CSS Library**: Linaria (Zero-runtime CSS-in-JS)
- **Drag & Drop**: @dnd-kit/core, @dnd-kit/sortable, @dnd-kit/utilities
- **Icons**: React Icons (lucide-react等)
- **Hosting**: GitHub Pages (GitHub ActionsによるCI/CDデプロイ)
- **Development**: Google Antigravity（AI コーディングエージェントを活用して実装）

## 💻 開発・セットアップ

プロジェクトを手元で実行・開発する場合の手順です。

### 1. 依存関係のインストール

```bash
npm install
```

### 2. 開発サーバーの起動

```bash
npm run dev
```
起動後、ターミナルに表示される `http://localhost:XXXX` にアクセスしてください。

### 3. 本番ビルド

```bash
npm run build
```
`dist/` ディレクトリに公開用のファイル群が出力されます。
